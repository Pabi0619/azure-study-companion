# Azure Study Companion

An interactive AZ-900 study companion built with vanilla HTML, CSS and JavaScript.

## Features

- Dashboard with progress tracking
- Flashcards
- Practice quizzes
- Quiz history
- PWA support (installable)
- Responsive design
- LocalStorage persistence

## Technologies

- HTML5
- CSS3
- JavaScript (ES Modules)
- LocalStorage
- Progressive Web App
